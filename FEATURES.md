|---|---|---|
| Global Roblox launch | Implemented | Official installed package |
| Roblox VN launch | Implemented | Separate package query |

| Custom presets | Implemented | Create, search, favorite, apply, delete |

| Full backup/restore | Implemented | Config, presets, favorites and history |
| Import/export | Implemented | Android document picker |
| JSON validation/format | Implemented | Object root; 1 MB config limit |
| Game-link opener | Implemented | Official Roblox links only |
| Device diagnostics | Implemented | Battery, thermal, RAM, display, network snapshots |
| Roblox HTTPS reachability | Implemented | Web endpoint check, not in-game ping |

| Shizuku/ADB/root FFlag writer | Not included | Would require privileged client-file access |
