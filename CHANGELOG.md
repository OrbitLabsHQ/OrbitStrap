# Changelog

## 1.2.0

- Prepared a clean GitHub commit workflow and mobile upload guide.
- Added an explicit Android feature compatibility matrix.
- Kept the independent Compose implementation and its existing workflows:
  launcher, Global/VN detection, flag editor, presets, history, backup/restore,
  Roblox link handoff, diagnostics and themes.
- Updated application version metadata and CI artifact naming.
- Clarified which Voidstrap-style capabilities are unavailable to a non-root Android app.
- No upstream Voidstrap source code or artwork was copied.
